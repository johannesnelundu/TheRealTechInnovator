02 / DIGITAL FUNDAMENTALS

Understanding the digital world

Start with the foundations before moving to advanced topics.

Hardware

Hardware is the physical equipment in a computer system. Examples include the processor (CPU), memory (RAM), storage drives, keyboard, screen and network adapter.

The CPU executes instructions. RAM holds data temporarily while programs run. Storage keeps files when power is off.

Software

Software is the collection of programs and instructions that tell a computer what to do. Operating systems manage resources, while applications help users perform tasks.

Examples include Windows, web browsers, text editors and games.

Operating systems

An operating system manages memory, files, processes, devices, accounts and permissions. It provides a platform for applications.

Windows, Linux, macOS and Android are examples of operating systems.

Data and information

Data consists of recorded facts such as numbers, text, images and measurements. Information is data organised or interpreted to provide meaning and support decisions.

Cloud computing

Cloud services provide computing resources over a network. They can include online storage, virtual servers, databases and software.

Cloud services are convenient, but account security, access controls, backups and privacy remain important.

Databases

A database organises data so it can be stored, retrieved, updated and analysed. Relational databases use tables; other databases support different data structures and access patterns.

03 / PROGRAMMING AND DEVELOPMENT

Build things with code

Programming means expressing instructions in a form a computer can execute. Different languages and tools are suitable for different tasks.

🌐

HTML

HTML defines the structure and meaning of web content. Headings, paragraphs, links, images, forms and navigation are created with HTML.

Example: <h1>Hello world</h1>

🎨

CSS

CSS controls presentation, including colours, spacing, typography, layouts, animation and responsive design.

Good CSS helps websites remain usable on both small and large screens.

⚙️

JavaScript

JavaScript adds behaviour to websites. It can respond to clicks, validate forms, update content and communicate with web services.

Example: console.log("Hello world");

🐍

Python

Python is a general-purpose programming language used for automation, data analysis, web backends, education and many scientific tasks.

Learn variables, conditions, loops, functions, lists and dictionaries.

🧩

Algorithms

An algorithm is a sequence of steps for solving a problem. Good algorithms define inputs, outputs, conditions and a clear process.

Practise breaking large problems into smaller, manageable tasks.

🐞

Debugging

Debugging is the process of finding and correcting software errors. Read error messages, reproduce the problem, inspect values and test one change at a time.

Development tip: Learn the basics first, create small working examples, and gradually combine them into bigger projects. Save versions of your code with Git and use a repository to track changes.
04 / CYBERSECURITY

Protect the digital world

Cybersecurity is the practice of protecting devices, accounts, applications, networks and information from unauthorised access, damage or disruption.

🔐

Confidentiality

Information should be accessible only to authorised people or systems. Access controls and encryption help protect confidential information.

🧾

Integrity

Integrity means information remains accurate and is not altered improperly. Hashes, digital signatures, permissions and audit records can help detect or prevent unauthorised changes.

⚡

Availability

Systems and data should be available when authorised users need them. Backups, maintenance, redundancy and recovery plans support availability.

🎣

Phishing

Phishing uses deceptive messages or websites to trick people into revealing credentials, paying fraudulent requests or opening dangerous attachments. Check links and verify unusual requests independently.

🦠

Malware

Malware is malicious software. Examples include ransomware, spyware and trojans. Use trusted downloads, update software, back up important files and avoid unknown attachments.

🛡️

Defence in depth

Use multiple protective layers: updates, strong authentication
