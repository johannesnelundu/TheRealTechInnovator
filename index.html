1. Computer Fundamentals

A computer receives data, processes it using instructions, stores it, and produces information.

Hardware

Hardware means the physical parts of a computer that you can touch.

  • Keyboard: enters text and commands.
  • Mouse: controls the pointer.
  • Monitor: displays information.
  • CPU: executes instructions.
  • Motherboard: connects major components.
  • SSD or hard drive: stores files and programs.

Software

Software is the collection of programs and instructions that tell a computer what to do.

System software: operating systems and device drivers.

Application software: web browsers, word processors, games, and media players.

Input, Processing, Output, Storage

Input: information enters the computer.

Processing: the CPU works on the information.

Output: the computer presents results.

Storage: information is saved for future use.

Example: typing numbers into a calculator is input; calculating is processing; showing the answer is output.

RAM and Storage

RAM is temporary working memory used by active programs. Its contents normally disappear when power is turned off.

An SSD or hard drive keeps files when the computer is off. RAM helps with multitasking, while storage keeps documents, photos, and applications.

Operating Systems

An operating system manages hardware, files, applications, users, and permissions.

Examples include Windows, Linux, macOS, Android, and iOS. Keep your system updated and use a secure screen lock.

Computer Maintenance

  • Keep devices clean and ventilated.
  • Install updates from trusted sources.
  • Back up important files.
  • Use a screen lock and strong passwords.
  • Do not install suspicious programs.
  • Restart the computer when troubleshooting requires it.

2. Programming and Problem Solving

Programming is writing instructions that a computer can execute to solve a problem.

Variables and Data Types

A variable is a named place for a value. Common data types include integers, decimals, strings, and Boolean values.

name = "Alex"
age = 20
height = 1.75
is_student = True

print(name)
print(age)

Here, name stores text, age stores a whole number, and is_student stores True or False.

Conditions

Conditions allow a program to make decisions.

score = 75

if score >= 50:
    print("Pass")
else:
    print("Keep practising")

The program checks whether the score is at least 50 and displays the appropriate message.

Loops

A loop repeats instructions. Loops are useful when the same task must be performed several times.

for number in range(1, 6):
    print(number)

This Python example prints the numbers 1 through 5.

Functions

A function is a reusable block of code that performs a task.

def greet(name):
    return "Hello, " + name

print(greet("Alex"))

The function receives a name and returns a greeting. Functions make programs easier to organise and maintain.

Algorithms

An algorithm is a clear sequence of steps for solving a problem.

  1. Identify the problem.
  2. Determine the required inputs.
  3. Plan the steps.
  4. Produce the expected output.
  5. Test the result and correct mistakes.

Errors and Debugging

Syntax error: code breaks the language rules.

Runtime error: a problem occurs while the program runs.

Logic error: the program runs but produces the wrong result.

Read the error message, inspect the relevant line, test a small change, and run the program again.

Practice task

Write a program that asks for a person's age and checks whether the person is 18 or older. Test it with 17, 18, and 25.

3. Web Development

Web development involves building websites and web applications. HTML provides structure, CSS controls appearance, and JavaScript adds interaction.

HTML: Structure

HTML creates headings, paragraphs, links, lists, images, and forms.

<h1>My Website</h1>
<p>Welcome to my page.</p>
<a href="https://example.com">
  Visit Example
</a>

The heading introduces the page, the paragraph displays text, and the link opens another page.

CSS: Design

CSS controls colours, fonts, spacing, borders, and layouts.

body {
  background: #080a0f;
  color: white;
  font-family: Arial, sans-serif;
}

h1 {
  color: gold;
}

Good CSS makes a website attractive, readable, and usable on different screen sizes.

JavaScript: Interaction

JavaScript can respond to user actions and change page content.

function welcome() {
  alert("Welcome, Tech Innovator!");
}

For example, a button can call this function when clicked.

How Websites Work

A browser requests a web resource from a server. The server responds with content, and the browser displays it.

A domain name is a readable website address. Hosting stores the files and makes them available online. HTTPS helps protect the connection between a browser and a website.

Publishing with GitHub Pages

  1. Create a GitHub repository.
  2. Add an index.html file.
  3. Open repository Settings, then Pages.
  4. Choose the correct publishing branch and folder.
  5. Wait for publishing to finish.
  6. Open the published website and test it.

Web Accessibility

Use readable text, strong colour contrast, clear headings, descriptive links, alternative text for meaningful images, and keyboard-friendly controls. Test the website on a phone as well as a computer.

4. Cybersecurity and Digital Safety

Cybersecurity protects devices, networks, accounts, and information from unauthorised access, damage, and disruption.

The CIA Triad

Confidentiality: information is visible only to authorised people.

Integrity: information remains accurate and is changed only appropriately.

Availability: systems and information are accessible when needed.

Passwords and MFA

Use a long, unique password for each account. A password manager can help you store them safely. Enable multi-factor authentication (MFA), which requires another form of proof beyond your password.

Never share verification codes with someone who contacts you unexpectedly.

Phishing

Phishing is a deceptive attempt to make people reveal information, open malicious files, or visit fraudulent websites.

  • Check the sender and website address.
  • Be careful with urgent threats and prizes.
  • Do not open unexpected attachments.
  • Verify suspicious requests using another trusted method.

Malware

Malware is malicious software. Examples include ransomware, spyware, viruses, and trojans.

Download applications from official sources, update software, review permissions, and keep important backups. Avoid pirated software and suspicious downloads.

Encryption

Encryption changes readable plaintext into ciphertext using an algorithm and a key. Decryption converts it back for an authorised recipient.

Symmetric encryption uses the same secret key to encrypt and decrypt. Public-key cryptography uses a related public and private key pair.

Real systems should use established cryptographic tools and protocols rather than homemade encryption.

Ethical Cybersecurity

Security testing must be authorised. Practise using your own devices or dedicated training labs. Do not access other people's accounts, devices, networks, or data without permission.

If you find a vulnerability, stop testing and report it responsibly to the owner.

Cybersecurity checklist

  • Update your devices and applications.
  • Use unique passwords and MFA.
  • Back up important files.
  • Check app permissions.
  • Think before clicking links or installing files.
  • Protect personal information and lock your devices.

5. Computer Networking

A network connects computers and other devices so they can exchange data and share resources.

Network Types

LAN: Local Area Network, such as a home network.

WAN: Wide Area Network covering a large area.

WLAN: a local network using wireless technology such as Wi-Fi.

The internet connects networks across the world.

IP Addresses

An IP address identifies a network interface so data can be sent to the correct destination. IPv4 addresses look like 192.168.1.10; IPv6 uses a longer hexadecimal format.

Routers and Switches

A router forwards traffic between networks. A network switch connects devices within a local network. Home routers often combine routing, Wi-Fi, and switching functions.

DNS

Domain Name System (DNS) translates domain names into records that help computers locate online services. It lets people use readable names instead of remembering IP addresses.

TCP and UDP

TCP provides reliable, ordered delivery of a byte stream. UDP sends datagrams without the same built-in delivery guarantees and can be useful for real-time applications that manage timing and loss themselves.

HTTP and HTTPS

HTTP is used for web communication. HTTPS uses TLS to protect the connection and help verify the website's identity. A padlock does not prove that a website or business is trustworthy; it indicates a protected connection to that site.

Basic network troubleshooting

  1. Check Wi-Fi, cables, power, and airplane mode.
  2. See whether other devices can connect.
  3. Restart the affected device if appropriate.
  4. Check whether one website or all websites are affected.
  5. Record the exact error and contact the service provider if needed.

6. Artificial Intelligence

Artificial intelligence (AI) describes computer systems that perform tasks such as recognising patterns, generating content, making predictions, or interpreting language.

Machine Learning

Machine learning uses data to train a model to identify patterns or make predictions. Supervised learning uses examples with known answers; unsupervised learning searches for patterns without the same labelled targets.

Generative AI

Generative AI can create text, images, audio, and code. It can help with brainstorming, learning, drafting, and explaining difficult concepts, but its answers may contain mistakes.

How to Use AI Wisely

  • Verify important facts and references.
  • Do not share passwords or confidential information.
  • Follow your institution's academic rules.
  • Review AI-generated code before running it.
  • Consider bias, fairness, privacy, and possible harm.

Writing Better Prompts

State the goal, audience, background, constraints, and desired format.

Example: “Explain IP addresses to a beginner, give two examples, and finish with three practice questions.”

7. Data and Databases

Data vs Information

Data is a collection of raw facts. Information is data organised or interpreted to answer a question.

For example, individual student scores are data. The class average calculated from those scores is information.

Databases

A database stores and organises data so it can be searched, updated, and managed. A relational database stores data in tables made of rows and columns.

A primary key uniquely identifies a row. A foreign key links related records.

SQL Example

SELECT name, score
FROM students
WHERE score >= 50
ORDER BY score DESC;

This query selects names and scores of students who scored at least 50, then sorts the results from highest to lowest.

Data Privacy

Collect only the personal data you genuinely need. Explain how it will be used, restrict access, keep it secure, and delete it when it is no longer needed. Never publish private information without proper permission.

8. Digital Skills and Online Research

Researching Information

Start with a clear question. Check who wrote a source, when it was published, what evidence supports it, and whether the author has a reason to persuade you. Compare important claims with independent, reliable sources.

Files and Email

Use clear filenames and folders. Before sending an email, check the recipient, subject, message, and attachments. Be careful with unexpected requests for money, passwords, or verification codes.

Cloud Computing

Cloud computing provides services such as storage, databases, and computing power over a network. It makes resources accessible from different devices, but accounts and sharing permissions must be secured.

9. Technology Careers and Projects

Build your skills by practising regularly and creating projects that demonstrate what you know.

IT Support Technician

Helps people solve computer, software, printer, account, and connectivity problems. Useful skills include troubleshooting, communication, operating systems, and networking basics.

Web Developer

Builds and maintains websites. Learn HTML, CSS, JavaScript, accessibility, version control, and responsive design.

Software Developer

Designs, writes, tests, and maintains applications. Learn programming fundamentals, algorithms, debugging, testing, and collaboration.

Cybersecurity Analyst

Helps monitor security risks, investigate alerts, and protect systems. Learn networking, operating systems, logging, security fundamentals, and ethical practice.

Data Analyst

Uses data to answer questions and communicate findings. Useful skills include spreadsheets, SQL, statistics, data cleaning, and visualisation.

Beginner Project Ideas

  1. Create a personal learning website.
  2. Build an interactive quiz.
  3. Write a simple expense tracker using sample data.
  4. Create a glossary of technology terms.
  5. Make a computer maintenance checklist.
